# Read the Full Issue Thread Before Scoping a Contribution

Promoted to a skill: invoke `git-plugin:git-issue-scoping` before building a PR,
plan, or prototype off a GitHub issue — including issues in repos you own — it
carries the full-thread `gh issue view --json comments` read (a WebFetch summary
drops the comments where the design was decided), the four things to extract
first (decided mechanism / scope ladder / in-flight dependencies / who's
driving), the search-before-filing and read-before-reversing checks for your own
tracker, and the re-verify-every-cited-`file:line`-at-HEAD pass for stale issues.
